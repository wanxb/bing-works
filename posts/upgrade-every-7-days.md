# 7天让自己升级一次，难度大吗？

## 工作

上周日晚上骤冷，晚上跑步没有做好保暖措施，导致着凉，原计划周四一早去客户那里，结果感冒加重，只好请假在家休息，周四周五连续两天在家没有出门，偶尔协助客户处理问题，空闲时间看书。

周六病情好转一早坐班车去客户那里，一整天都在处理问题。晚上的跑步计划被下雨打乱，只好改为周天。

本周研究了 GitHub 的上传和下载用法，越用越喜欢，在上面也发现了不少好的开源程序和用户，GitHub 不愧是全球最大的同性交友网站，哈哈！好久之前就注册了，不过一直没有花心思在上面，作为程序员，汗颜！

上周在腾讯云花了 124/5 年买了域名 xunbing.wang，当时想解析一个 GitHub Page，按照一个老师的配置方法配置类型 A 和 CNAME，结果 GitHub 怎么也解析不到，捣鼓了好久也没有解决，就放在了一边。

周一询问刚同学找工作的进展，并把我的域名发给了她看，谁知她也给我发过来一个域名 gangyuanyuan.top，上去一看我就了解，多半是为了找工作做的，不过做的不错，下了不少功夫。

和她交流了半天域名的问题，一开始我以为是我域名没有备案的原因，不过后来一想 GitHub Page 不在国内也不用备案，还是在解析那出的问题，于是认真检查了一遍，这次果然发现了问题，解析问题顺利解决，真心感谢刚同学。

由于域名解析问题解决，周一下班后用了一个晚上时间做了个人网页，不过是模仿 Kards 的页面。期间一个图片二维码显示问题，还把小冷拉起来帮我找原因，在她的指点下顺利搞定。

本周在李骏老师的课上认识了 Markdown，一种轻量级的标记语言，相比 HTML 减少了大量的标签，更易读易写，空闲时间去看了源文档和一些基本用法，很简单易学。

本周搞定了 Google，使用了一周，果然墙外的世界真香！

## 阅读

**《小强升职记：时间管理故事书》** 作者 邹鑫

该书绝对是职场人必读的时间管理方面的入门好书，它不是理论层面的概念说教，而是以第三人称小强学习时间管理一路成长作为案例，来讲述时间管理的重要性。

> 时间死循环：越忙越乱，越乱越忙。

首先可以通过时间日志找到自己的价值观和工作高效率的时间点。运用四象限法则，要事第一，第二象限优先，像甩猴子一样（猴子法则）处理第三象限的事情，压缩压缩再压缩第四象限的事情。

像整理衣柜那样整理好自己待办的事情，归类汇总划清界限，需要的时候到对应的地方去取，做到选择时间最短，行动速度最快。

用 SMART 法则理清目标，用思维导图梳理计划，用甘特图掌控进度，用九空格平衡人生，让优秀成为习惯。

**《嫌疑人X的献身》** 作者 东野圭吾

一个高智商的数学老师，为了报恩（爱）而帮助隔壁母女遮蔽杀死母亲前夫的事实，使用张冠李戴的手段多次误导警方视线，最后在快要查清楚真相之前，更是以诋毁自己的方式再次引导警方相信自己就是杀人者……

> 设计别人解不开的问题和解开那个问题，哪个更难？自己想出答案和确认别人的答案是否正确，哪个更容易？

**《这样读书就够了：个人学习力升级指南》** 作者 赵周

从读书到"拆书"，把书拆为己用。运用 RIA 读书法：Reading 阅读原书内容；Interpretation 讲解引导，理解知识点并关联自己；Appropriation 拆为己用，A1 找到相关案例，A2 建立目标与行动，把应用落地，把知识转化为能力。

> 学习能力 > 其他能力

**《系统之美：决策者的系统思考》** 作者 德内拉·梅多斯

系统包括三个部分：要素、连接、功能或目标，具有适应性、动态性、目的性，并且可以自组织、自我保护与演进。增强回路会使系统存量变大、能力变强，但超过系统的承受能力之后系统就会崩溃，这时候就需要系统反馈和调节回路。系统无处不在，并且具有层次性，系统之上还有系统。

> 系统使整体大于部分之和。

这本书值得认真多次阅读、理解。

## 电影

**《少年的你》**

讲述高中校园欺凌的问题，这个问题最近屡见不鲜，随着社会的变迁，孩子变得也越来越早熟，一群坏孩子聚在一起，彼此交流坏心思，并且自以为人多底气足，欺负看不顺眼的同学。要解决这个问题需要多方共同发力，社会、学校、老师、家长、学生自身和法律层面等。

给我留下印象最深的是：一开始小北保护陈念只能在深夜，看不见的角落里，带着帽子，看不见脸，而电影最后依旧是在保护陈念，却是在阳光下，露着少年帅气的脸。

> 你只管往前走，我就在你身后，你保护世界，我保护你。
