# SSD 更换笔记

## 背景

原来的笔记本用的是 Windows 8.1，虽然能用但速度越来越慢。正好手头有块 SSD，就打算换上并顺便升级到 Windows 10。

## 翻车之路

**第一关：分区翻车。** 安装 Windows 10 时不小心选错了分区，把原来 Windows 8.1 所在的 C 盘给格了。等发现时已经晚了，好在之前的数据都有备份。重新分好区后，一路顺利装完了 Windows 10。

**第二关：SQL Server 2008 安装失败。** 因为工作需要 SQL Server，开始安装 SQL Server 2008。安装过程中提示了一个不太重要的警告，没在意继续装。接着装 VS 2013，装到一半提示核心功能安装失败——之前也没遇到过这种问题，也没多想，硬着头皮重新装了一遍 VS 2013，还是失败。

**第三关：Windows 10 屏幕闪烁。** 最新版的 Windows 10 系统开始频繁出现屏幕闪烁，一查说是显卡驱动兼容问题。尝试重置默认驱动，重启之后果然好了。但没过一会又开始闪烁。不管了，继续装 VS 2013，结果中途又提示核心功能安装失败。以为是后台有进程一直占着没发现，干脆断了网、卸载了没用的程序再试，依旧如此。

## 找到根源

折腾了半天，决定还原系统。记得上次 Windows 8.1 装 VS 2013 是没问题的，去搜索了一下，果然——直接重装系统，干净利落地装好 Windows 10，然后第一时间关掉自动更新、关掉 Defender、关掉 Host 相关服务，重新安装。

这次先装 SQL Server 2008，一步步小心操作，等着安装。这时右下角弹出一个提示有程序需要修改默认设置，我仿佛找到了问题的根源——由于打开了 Host 安装的服务，还是被莫名地惊喜了一下，看不见的服务已经深深地潜伏在了系统里，不过还是在期待着安装顺利完成，然而还是失败了。

## 终局

二话没说，断了网再装。这次决定不再打开 Host 安装，直接解压 ISO，一步步操作，小心翼翼装完系统。果然没有什么乱七八糟的服务带出来，出于安心还是关了更新和 Defender。

这次肯定可以的，我暗自鼓劲。怀着忐忑的心情装好了 SQL Server 2008，期间没有一点异常提示；接着装 VS 2013，也是一路顺风。哈哈哈，终于搞定了！这一刻我一拳砸在了桌上——太TM不容易了，感觉自己快要哭出来了。就为了换个 SSD，我受了多少罪，生了多少气。

接下来的工作就顺利了：系统从天上到地下，又从地下到天上，足足折腾了一整天。

> 系统一定要装纯净版的，拒绝被各种服务捆绑！吃一堑长一智，以后再遇到这样的问题就不会搞这么久了，这过程太痛苦了。
